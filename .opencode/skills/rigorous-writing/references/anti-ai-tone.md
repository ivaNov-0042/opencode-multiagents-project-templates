# 去 AI 味专章（反例 → 改写对照）

> 本章是本 skill 的立身之本。下列「反面示例」取自导入本 skill 时的源项目报告
> （2026-10-01；原始相对路径从略，那些文件不在本仓库），改写示例为相应的中性、可验证写法。
> 取证命令：见文末 §11「如何自行取证」。

「AI 味」的本质不是用词洋气，而是**用视觉强调（加粗/emoji/破折号/口号）来冒充论证强度**，
以及**用比喻与修辞替代可验证的表述**。以下 10 条逐条给规则 + 真实反例 + 改写。

---

## 1. 不写口号式结论

**规则**：禁止 `## 0. 一句话结论`、`划重点`、`兜底证据`、`隐藏冠军`、`常青` 这类小标题；
标题改为**带条件与量级的陈述句**。

| 原文（出处） | 改写 |
| --- | --- |
| `## 0. 一句话结论` | `## 0. 结论：跨境与商品 QDII 的周期性高溢价由申购通道关闭驱动` |
| `**最"常青"的高溢价品种**（累计天数）`（同源报告） | `**累计高溢价天数最多的品种**（口径见下注）` |
| `> **本清单外的"隐藏冠军"**：…`（同源报告） | `> **名单外仍有高溢价品种**：…（同一口径，未进入前十）` |
| `## 9. 一句话总结` | `## 9. 结论` |

## 2. 加粗只用于术语首次定义或关键数值

**规则**：正文加粗 **≤ 10 处/百行**；同一句不超过两处加粗；不整句加粗。
**导入时源项目实测**（见 §11 取证命令）：加粗密度最高的三份报告分别达 **146 处/百行**
（254 处 `**` / 174 行）、129.7、95.0。

| 原文（出处） | 改写 |
| --- | --- |
| `**只要「一级市场申购通道被掐断」，场内就会周期性长出高溢价。**` 整句加粗（源报告） | `一级市场申购通道被掐断时，场内会周期性出现高溢价。`（不加粗；术语「申购通道」首次出现时加粗一次即可） |
| 一句内 `**2.55 万亿**（2019 年的 **7.0 倍**）`（同源报告） | 一句内只保留一处加粗：`成交额达 2.55 万亿元，为 2019 年的 7.0 倍` |

## 3. 不用 emoji 与装饰符号

**规则**：`✅ ⚠️ 🔥 ✨ 📌 💡 🚀` 及勾叉星标一律删除，改为中性文字。
**导入时源项目实测**：全库报告中 `✅` 出现 **539 次**、`⚠️` **148 次**。

| 原文（出处） | 改写 |
| --- | --- |
| `| 类别 | … | ✅ 每次外盘行情 + 额度见底就复发 |`（源报告） | `| 类别 | … | 是，随外盘行情与额度见底反复 |` |
| `| **QDII 商品限购** | … | ⚠️ 结构型，非情绪型 |`（同源报告） | `| … | 结构性，非情绪型 |` |
| `> ⚠️ **两个必须剔除的假信号**`（同源报告） | `> **两个必须剔除的假信号**` |
| `> 📌 report/02 §4.1 曾指出…` | `> report/02 §4.1 曾指出…` |

## 4. 少用破折号 `——`

**规则**：`——` 改为逗号、冒号或拆句；密度 **≤ 2 处/百行**。
**导入时源项目实测**：全库报告中中文破折号 **218 处**。

| 原文（出处） | 改写 |
| --- | --- |
| `高溢价**必须用成交量/换手率过滤**——成交萎靡的品种要么是报价不动…`（源报告） | `高溢价必须用成交量/换手率过滤：成交萎靡的品种要么报价不动…` |
| `**并非"从 2024 年起跳"**，而是…——`（拆句即可） | 去掉破折号，用逗号或分号连接。 |
| `## ② BankFocus —— 银行与金融机构专用` | `## ② BankFocus：银行与金融机构专用` |

## 5. 禁止修辞反转套式

**规则**：`不是 X，而是 Y`、`与其说 X 不如说 Y`、`并非 X 而是 Y`、`而非 Y`、`而不是 Y`
→ **直接陈述 Y 并给证据**。

> **为什么这条特别重要（2026-09-30 补充，2026-10-01 加深）**：这类句式有两个独立的毛病。
>
> **毛病一：凭空造靶。** 多数情况下，读者和作者都从未认为过「X」，所谓「不是 X」是在对抗一个
> 不存在的立场；作者真正想说的只有 Y。这样的对仗让句子看起来像在做判断、在做区分，实际上没有
> 任何信息增量，只是用修辞冒充论证。
>
> **毛病二：位置错配（更隐蔽）。** 这类句式靠**先否定读者脑中已有的念头**来制造顿挫感。如果读者
> 脑中根本没有那个念头，否定就没有着落点。**典型场景就是文章开头、以及任何概念首次出现处**：
> 读者此时对全文和术语都还没有概念，突然读到「不是 X」，只能卡在「X 是什么？我为什么要关心它
> 是不是 X？」。研究型、说明型文章的职责是**直接交代事实、分析、结论**，读者需要一个可以站立的
> 立足点，而不是一个被悬念绊住的台阶。开场应先用陈述句说明「这是什么、本文要讲什么」。
>
> 判断方法：写下「不是 X，而是 Y」后自问两个问题——**① 除 Y 之外，是否真的有人会主张 X？
> ② 读者读到此处时，脑中是否已经存在 X 这个概念？** 两问都答「是」才可用；否则删掉 X 那半句，
> 直接写 Y 及其证据。
>
> 反例与改写（源报告实例，含位置错配的实例）：

| 原文（出处） | 问题 | 改写 |
| --- | --- | --- |
| `**溢价是通道收紧的体温计，不是大盘资金的水位计。**`（源报告） | 修辞反转 + 比喻，双重违规 | `溢价的水平由申购通道是否关闭决定，与大盘资金总量几乎无关：溢价与两市成交额相关仅 0.086，与个券换手率相关 0.248（`market_corr.csv`）。` |
| `**并非"从 2024 年起跳"**，而是 2020-2021 与 2025 两个高峰`（同源报告） | 无人主张「从 2024 年起跳」 | `2020-2021 与 2025 是两个高峰；2024 年（72 只）低于 2021 年（97 只），不构成起跳点。` |
| `这不是渐进下滑，而是**一次性断裂**` | 「渐进下滑」是虚设靶 | `2022-04 单月环比 −26.5，为全期最大；此前的历史最大单月跌幅为 −10.4（2003-04）。` |
| `**2001–2008 并非低位徘徊，而是 108–114 的高位平台**`（同源报告） | 同上 | `2001–2008 的年均为 108–114，高于 1999–2000 与 2009–2011（见 §2 表）。` |
| `### 6.3 结构分化：并非"消费消失"而是"消费转移"`（同源报告） | 标题里造靶 | `### 6.3 结构分化：总量稳定、分项之间发生转移` |
| `理解这一点，才能理解为什么指数是"情绪"而非"事实"` | 无人把该指数称作「事实」 | `理解这一点，才能理解该指数的性质：它汇总的是受访者的态度，问卷里没有可直接换算的数量。` |
| **开场句**`消费者信心指数不是从交易数据里算出来的，它来自一项独立的住户态度调查`（同源报告） | **位置错配**：位于第一章首句、读者对「消费者信心指数」尚无任何概念，无从判断它「是不是从交易数据算出来」 | `消费者信心指数来自一项独立的住户调查。按国家统计局官网的公开说明，全国消费者信心调查的要点如下：` |
| `**它度量的是主观判断的分布，而不是客观数量**`（同源报告） | X 与 Y 并非互斥选项 | `它度量的是主观判断的分布；问卷不采集可直接换算的数量。` |
| `先行性主要体现为"同步放大器"而非"提前预警器"`（同源报告） | 两个词都是作者自造，非既有立场 | `先行性有限：它与消费拐点在月度层面同步出现，滞后 1 期自相关 0.971。` |

## 6. 禁止比喻化营销措辞

**规则**：`专利（比喻义）/ 重灾区 / 之谜 / 体温计 / 水位计 / 烧起来 / 护城河 / 天花板`
等一律改中性技术表述。

| 原文（出处） | 改写 |
| --- | --- |
| `### 2.2 跨境 vs 境内：溢价是跨境品种的"专利"`（源报告） | `### 2.2 高溢价集中在跨境品种：2025 年跨境类占比 46.7%，境内股票 ETF 仅 3.7%` |
| `### 2.3 ETF vs LOF：LOF 是更严重的"重灾区"`（同源报告） | `### 2.3 LOF 的高溢价比例高于 ETF：2025 年为 35.9% 对 10.0%` |
| `| **II 折价之谜** | 2000-2020 |`（同源报告） | `| **II 长期折价** | 2000-2020 |` |
| `- **老封闭式基金（折价之谜）**`（同源报告） | `- **老封闭式基金（长期折价的截面特征）**` |
| `真正能把溢价"烧"起来的，永远是有量的大品种。`（同源报告） | `高溢价只出现在成交额较大的品种上；成交 <1000 万元的品种基本贴近净值（§6）。` |

## 6b. 禁止类比类动词

**规则**：不要用**物理动作或生物过程**去描写市场现象。市场变量只有方向与量级，
用「掐断/挤爆/长出/撑起/引爆/吞噬/腰斩/蒸发/输血」描述时，读者得到的是一幅画面而非一个事实。

| 类比动词（禁用） | 中性技术动词（推荐） |
| --- | --- |
| 掐断、切断通道 | 暂停、关闭、停止申购 |
| 挤爆、冲爆 | 申购需求超过额度、申购受限 |
| 长出、长出来 | 出现、形成 |
| 烧起来、慢烧 | 上升、扩大 |
| 撑起行情 | 支撑、推动 |
| 水涨船高 | 同向变化 |
| 引爆、点燃、井喷、熄火 | 触发、大幅上升、回落 |
| 吞噬、吃掉、虹吸 | 吸收、分流、占用 |
| 腰斩、蒸发、断崖、崩塌 | 下跌约一半、大幅下降 |
| 输血、抽血、供血 | 补充资金、占用资金 |

**反例 → 改写**（源报告）：

- 差：`**只要「一级市场申购通道被掐断」，场内就会周期性长出高溢价。**`
- 好：`一级市场申购通道暂停后，场内会出现周期性高溢价。`

- 差：`抄底资金挤爆限购通道`（同源报告）
- 好：`申购需求超过限购额度`

- 差：`看起来"水涨船高"，但下面两件事把它证伪了。`（同源报告）
- 好：`两类指标同向上升；但分档检验不支持"资金总量决定溢价水平"这一解释。`

> **保留字面义**：若某词是本领域的通用术语（如供应链语境下的「技术卡位」、项目里的
> 「卡位」作为名词），保留；只禁止把物理/生物动作**比喻地**用于市场变量。
> 边界词由 `style_lint.py` 报 `warn`，交人工判断。

## 7. 禁止空洞强调与主观程度词

**规则**：`非常 / 极其 / 极为关键 / 无疑 / 显然 / 众所周知 / 必然是` → 改为可验证量化陈述。
（`style_lint.py` 会对 `显然/众所周知/无疑/必然是` 直接报 error。）

- 差：`这一点无疑是本次分析最关键的发现。`
- 好：`该系数为 0.248，在本组四个相关系数中绝对值最大（`market_corr.csv`）。`

## 8. 列表节制

**规则**：能写成连贯段落的不拆 bullet；bullet 只用于**可枚举的并列项**
（参数、分档、清单、代码路径），不用于承载论证。

- 差：把「为什么 LOF 更严重」拆成 4 条 bullet，每条一句话。
- 好：写成一段——「LOF 场内存量份额少、单日申购有限额、申赎确认 T+1~T+2，
  套利资金难以完成跨市场套利，因此高溢价比例高于 ETF。」证据（35.9% vs 10.0%）随句给出。

## 9. 去掉「元话语」

**规则**：`本节将…`、`接下来我们…`、`需要注意的是…`、`如上所述` 大量删减；直接写内容。

- 差：`需要注意的是，本节将重点讨论溢价的成因，接下来我们会看到……`
- 好：删掉整句，直接进入成因的第一句。

## 10. 中文标点与排版

**规则**：中文用全角标点；中英文数字之间不加多余空格；数字与单位的写法全仓库统一
（统一写 `44.8%`、`2.55 万亿`，不写 `44.8 %`；也不要在 `2.55万亿` 与 `2.55 万亿` 之间混用）。
引号统一（导入时源项目混用直引号 `"…"` 与直角引号 `「…」`，应择一并统一：
`「`/`」` 共 344 个、直引号 `"` 约 1250 对，应以全角引号为准）。

## 11. 如何自行取证

```bash
# 在仓库根目录执行

# 列出报告
find output -name "*.md" | head

# 装饰符号与破折号计数
grep -rho "——" output/*/report/*.md | wc -l
grep -rho "✅"   output/*/report/*.md | wc -l
grep -rho "⚠️"   output/*/report/*.md | wc -l

# 加粗密度（按文件排序）
for f in output/*/report/*.md; do
  echo "$(grep -o '\*\*' "$f" | wc -l) / $(wc -l < "$f")  $f"
done | sort -rn | head

# 定位典型反例
grep -n "一句话\|兜底\|隐藏冠军\|常青\|专利\|重灾区\|之谜\|体温计\|水位计" \
     output/*/report/*.md
```

### 12.2 修复后（本 skill 规则的验收标准）

同一文件按本 skill 逐条改写后：

```
==============================================================
汇总：1 个文件 / 384 行，命中 0 处（error 0，warn 0）
按规则：（无命中）
==============================================================
```

要点：清除 emoji 与口号式标题、把类比动词换成中性技术动词（掐断→暂停、长出→出现、
挤爆→申购需求超过额度、水涨船高→同向上升）、把反问式比喻换成带数字的陈述、
加粗从 95 处/百行降到 3 处/百行（只保留术语定义与关键数字）、破折号降为 0。

> 交付标准：`style_lint.py` 对本主题报告返回 0，且 `verify_claims.py` 仍全 OK
> （本例 121/121，证明**改文风不改数字**）。

导入时源项目的全库横断面（37 个文件 / 12,998 行）作为存量基线：

```
汇总：37 个文件 / 12998 行，命中 1486 处（error 1252，warn 234）
按规则：emoji=1175，emdash=220，analogy_verb=24，bold_density=31，slogan=13，metaphor=12，inversion=7
```

> 结论：源项目存量报告的主要「AI 味」来源是 emoji（1,175）与破折号（220），
> 其次是加粗密度（31 个文件超阈值）、类比动词（24）与比喻化措辞（12）。
> 改写优先级：先删 emoji，再降加粗密度，再替换类比动词/比喻与破折号。
> 注：上列数字随报告被修改而变化，属正常；关键是同一时刻可复现。
