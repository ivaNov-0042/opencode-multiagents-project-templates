# 绘图规范

- **年度数据**：横轴必须逐年标注（每年一个刻度），不得使用 2/4/6 年等稀疏刻度。
- **图例（legend）**：条目 >8 时放图外（`bbox_to_anchor=(1.01, 1)`），不得压住数据。
- **分辨率**：统一 `dpi=220` 输出，保证可读。
- **画幅比例**：
  - **长时间序列图必须用横向画幅**（宽 > 高），建议 `figsize` 宽:高 约 `1.5:1`（如 `14×9`）。多子图用**上下排列**（`plt.subplots(2, 1, ...)`）。时间轴横向展开，竖幅或左右分割会把 20 年以上的序列压成锯齿，读不出形态。
  - 仅在两个变量的**量纲相同、需要逐点对照**时才用左右双轴；否则一律上下排列。
  - 单张不含时间轴的图（柱状、饼图、热力图等）不适用本条，按内容选比例。
- **图内标注不得压数据**：`axhline`/`axvline` 的说明文字放数据稀疏处，必要时加白色底衬（`bbox=dict(facecolor="white", alpha=0.9, edgecolor="none")`），或直接并入图例。

## 收尾

- [ ] 长时间序列图使用横向画幅（宽 > 高）、多子图上下排列；图内标注未压住数据
