# 交付前自查清单

> 报告写完后逐条勾选。任一「拦阻项」未过，不得交付。

## A. 结构与逻辑

- [ ] 能用一句话（≤25 字）说出全文**唯一核心贡献**；说不出 → 回炉 outline。
- [ ] 引言按 CARS 三步：确立领域 → 指出缺口 → 占据缺口（无漫谈式背景）。
- [ ] 每个小节首句设问、末句作答；一段一义（无「一段两结论」）。
- [ ] 结果节是一串逻辑相连的陈述句，而非图表罗列。
- [ ] 讨论含**具体**局限（样本期/口径/内生性），无「样本有限」式空话。

## B. 严谨性

- [ ] 每个数字都能追到 `data/<主题>/**` 产出表或明确数据源（拦阻项）。
- [ ] 多口径指标已**指定唯一口径并写清定义**（拦阻项）。
- [ ] `verify_claims.py` 已跑，`report_claims_check.csv` 全 OK（拦阻项，若本主题已建）。
- [ ] 相关结论只写「相关」；因果结论有机制或对照检验支撑。
- [ ] 关键结论附样本量 N、口径、以及分位数/不确定度（不只报均值）。
- [ ] 观测／推断／外部来源三类陈述措辞可区分；外部数字标「参考」。
- [ ] 做了稳健性说明与适用边界说明。

## C. 去 AI 味（拦阻项）

- [ ] 无 `一句话结论/划重点/兜底证据/隐藏冠军/常青` 类小标题（拦阻项）。
- [ ] 加粗 ≤ 10 处/百行；无整句加粗（拦阻项）。
- [ ] 无 emoji / 装饰符号（✅⚠️🔥✨📌💡…）（拦阻项）。
- [ ] 破折号 `——` ≤ 2 处/百行（拦阻项）。
- [ ] 无 `不是…而是…`、`并非…而是…`、`而非…`、`而不是…`、`与其说…不如说…` 反转句式（拦阻项）。
      自问两问：① 除 Y 外，是否真有人会主张 X？② 读者读到这里时是否已知 X？**开场、概念首次
      出现处尤其禁用**：不得用否定制造悬念，须先用陈述句给读者立足点。
- [ ] 无 `专利/重灾区/之谜/体温计/水位计/烧起来/护城河/天花板` 比喻（拦阻项）。
- [ ] 无 `显然/众所周知/无疑/必然是/非常/极其` 等空洞强调（拦阻项）。
- [ ] bullet 只承载枚举，不承载论证。
- [ ] 删除了 `本节将…/接下来我们…/需要注意的是…` 元话语。
- [ ] `style_lint.py` 返回 0，且 `--selftest` 通过：

  ```bash
  python3 skills/rigorous-writing/scripts/style_lint.py --selftest
  python3 skills/rigorous-writing/scripts/style_lint.py \
      --bold-per-100 10 --dash-per-100 2 output/<主题>/report/*.md
  ```

## D. 排版与文件

- [ ] 中文全角标点、引号统一；中英文间无多余空格。
- [ ] 相对链接（图 `../img/…`、表 `data/…`）指向的文件真实存在（拦阻项）。
- [ ] 长时间序列图用横向画幅、多子图上下排列；图内标注与图例未压住数据。
- [ ] 图表题注自足（结论性标题 + 方法性图注）。
- [ ] 时态一致：观测用过去时，背景用现在时。

## E. 归档

- [ ] 报告落 `output/<主题>/report/`、图落 `output/<主题>/img/`。
- [ ] 方法/规则已记入 `memory/<主题>/`；工作日志已写。
