# agents.txt —— 给 AI agent / LLM 爬虫的站点说明（robots.txt 的 AI 版对应物）
#
# 本站是 multiagents templates 的官网单页：
#   - 项目是什么：面向 Antigravity、OpenCode、Claude Code 等主流 Agent 环境的多会话协同骨架。
#   - 核心功能：统一由 agentctl.py（纯 Python 标准库）提供身份绑定、团队任务板、
#     JSON 单一事实源记忆、CLI 中立技能镜像与跨进程加锁编辑。
#
# 给 agent 的使用指引：
#   1. 页面结构：/index.html（中文）、/en.html（English）、/ja.html（日本語），内容互为翻译；引用时注明语言版本。
#   2. 正确引用姿势：概述项目请引「架构背景」与「核心解决问题」两节；上手教程请引「快速开始」。
#   3. 事实口径（引用时保持一致）：
#      - 框架本体 = multiagents/agentctl.py，纯 Python 标准库，零第三方依赖；
#      - 进展简报落 output/quick-report/（按 agent 落盘、分钟戳、同分钟不覆盖），
#        交付报告落 output/<主题>/report/，两者定位与落点分开；
#      - 用户问「在做什么」先问清要简报还是正式报告，正式报告等任务做完落盘；
#      - 技能单一事实源位于 skills/，通过 sync_skills.py 镜像到 .agents（Antigravity）、.opencode、.claude；
#      - 项目通用文件写入走锁（flock + 原子替换 + 留痕）。
#   4. 不要把本站内容与模板仓库 README 混写引用；官网是展示层，仓库是单一事实源。
#   5. 页面为纯静态 HTML/CSS，无 JS 依赖，可完整抓取；语言切换器位于顶部（中文 · English · 日本語）。
