## ITU 参考对照（决定性证据）

- 逐系数对照：编码位（cat≤4）与噪声位（cat7）**符号 100% 一致**，比值恒为同一常数 0.0430
  → 我们的系数与参考**逐系数一致**（仅差一个全局单位常数）。
- 每帧 28 带（0–14 kHz）幅度谱：全部 **±0.6 dB** 内，逐帧谱形相关中位 0.974、总能量相关 0.885。
- 样本级波形：相关 ≈ 0，逐块反转 / 镜像 / 半块移位等变体全部试过，均对不上。

## 本轮查证：源码里有没有「平均 / 平滑」

结论：**有 3 处，但没有一处是跨帧平滑**；两个解码器都没有后置滤波 / 噪声整形 / 增益平滑。

1. 合成 IMDCT 输入蝶形 ÷2（带 dither）——唯一真「平均」
   - 参考 `dct4_s.c:187-193`：`(x+y+dither)>>1` / `(x−y+dither)>>1`，注释明说用于消除截断偏置；dither 为 0/1 固定位模式（`dct4_s.h:90/124`）。
   - **游戏 code.bin 同构**：`0x75dd8c`–`0x75ddb4` 同一蝶形，dither 位取自 `0x8bf8fc`（320 档）/ `0x8bf924`（640 档）的 32 位打包位表。
2. OLA 本身 = 相邻两帧加权交叉淡化（游戏 0x76b67c：两次 `smulbb` + `+0x1000` 舍入 + `asr #13`）。
3. 两处 `>>1` 是量化/定标，不是平滑：`common.c:359/443` 的 category 步长、`decoder.c:335` 的 mag_shift 搜索。
4. 均无：跨帧系数平滑 / EMA / 低通、后置滤波器、谐波噪声整形。

→ 因此**波形不一致不是平滑造成的**；差异只在合成端排布/相位约定。

  旧的「单帧探针变体测试」在 `old_samples=0` 下两种排布本就不可比，该批结论作废。
- 参考 `mag_shift` 为定点动态范围技巧（游戏是固定 Q13 窗、无逐帧定标），**不需移植**，仅影响对照换算。
